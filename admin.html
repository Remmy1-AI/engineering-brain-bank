Connect Supabase

The owner dashboard needs your Supabase Project URL and anon (public) key.

  1. Create a free project at supabase.com.
  2. Open SQL Editor → paste and run supabase/schema.sql from this repo.
  3. Authentication → Users → Add user (email + password for the owner).
  4. Project Settings → API → copy Project URL and anon public key.
  5. Paste them into js/supabase-config.js, commit & push (or edit on GitHub).

Never put the service_role key in the front end or this repository.
